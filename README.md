# Stellwerk Tycoon

Eigenständiges Eisenbahn-Infrastruktur- und Verkehrsunternehmensspiel.

Diese Repository-Version wird aus dem bestehenden Stellwerk-Tycoon-Projekt weiterentwickelt; das Stellwerk-Spiel bleibt separat.

## Starten

Nach dem ersten Entwicklungs-Pull-Request `index.html` im Browser öffnen. Das Spiel benötigt keinen Server und speichert Spielstände lokal im Browser (`stw_tycoon_v2`).

## Entwicklung

Änderungen werden auf Entwicklungsbranches und über Pull Requests mit Regressionstests überprüft.
